# 4. Pre-lancio

Prima di andare online. I punti legali e di sicurezza rimandano ai file 1-3.

## Legale e sicurezza
- [ ] Pagina privacy policy (vedi 2)
- [ ] Pagina termini e condizioni (con takedown se c'è UGC)
- [ ] Nessun segreto nel frontend (vedi 1)
- [ ] HTTPS forzato (redirect + HSTS)
- [ ] Cookie consent banner (vedi 2)

## SEO e condivisione
- [ ] Meta title e description unici per pagina
- [ ] Immagine anteprima social (Open Graph, Twitter card)
- [ ] Favicon
- [ ] Sitemap e robots.txt
- [ ] Alt text sulle immagini

## Performance e accessibilità
- [ ] Immagini compresse (WebP/AVIF, dimensioni corrette)
- [ ] Velocità di caricamento verificata (Lighthouse)
- [ ] Contrasto colori WCAG AA
- [ ] Mobile friendly

## UX e affidabilità
- [ ] Pagina 404 personalizzata
- [ ] Nessun link rotto
- [ ] Validazione form lato client e server
- [ ] Anti-spam sui form (honeypot, captcha, rate limit)

## Conversione
- [ ] Analytics configurati, attivi solo dopo il consenso
- [ ] Una call to action chiara
